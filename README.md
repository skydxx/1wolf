# 1wolf.ru — публичный сайт клана

Публичная часть сайта [1wolf.ru](https://1wolf.ru): страницы клана, новости, состав, заявки, личный кабинет, вход через Discord и карточки боёв. Flask, Jinja, SQLite.

Здесь опубликован отдельный снимок публичного приложения. Код панели управления, ботов, рабочая база, загрузки пользователей, секреты и конфигурация сервера в этот репозиторий не входят. Для функций, связанных с ботом и панелью, нужны собственные сервисы и переменные окружения.

## Локальный запуск

```bash
python3 -m venv venv
./venv/bin/pip install -r requirements.txt
cp .env.example .env
./venv/bin/python run_public.py
```

Страница будет доступна по адресу <http://localhost:5055>. Без настроенного Discord OAuth вход и регистрация через Discord недоступны; публичные страницы и форма заявки работают локально. Не используйте пример секретного ключа в продакшене.

В продакшене приложение запускается за доверенным локальным reverse proxy. `PUBLIC_SECRET_KEY` должен быть случайной строкой длиной не менее 32 символов. Загруженные файлы хранятся вне веб-корня. Для отправки заявок и входа действуют CSRF и лимиты по IP.
